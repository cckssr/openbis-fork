# 7.0.0 - Early Access Release

```
IMPORTANT: Early Access releases must NOT be used in production. No support is provided for such releases used in production environments.

Early Access releases can be used by development teams who want to have early access to new openBIS functionalities that will become generally available with the next official major release.

Features present in an Early Access release are expected to evolve over time and might even be removed.

Early Access releases should be considered a checkpoint in the roadmap to the next major release.
```

## Release notes

**We recommend this version for new openBIS users**

**Established openBIS users are strongly encouraged to:**
- Migrate to the latest 20.10 release available (currently 20.10.12.5) before upgrading to 7.0.0
- Test this release on a staging server before using it in production. A General Availability release will be made available later this year.

**A migration guide for 20.10.x will be made available shortly.**
